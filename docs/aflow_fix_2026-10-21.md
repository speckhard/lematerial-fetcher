# AFLOW fixes — 2026-10-21

A failed page now stops the fetch without recording a completed version. The
parent reads pages in small groups and checks every future, including a worker
that crashes before it can report an error. Only a valid empty page means the
end of the source. Both normal and debug modes check failures. Database and HTTP
connections are closed after each page.

A failed run may leave already-written pages in its raw table. This fix does not
make the whole download transactional. Do not transform a failed table; use a
new table for another attempt. The existing version must not be read as proof
that a partially changed table is a new completed snapshot. Full database/process
integration and campaign download bounds remain required before production use.

The structure transform now requires a nonempty explicit PAW_PBE declaration.
Missing, empty, mixed or unsupported declarations are not called PBE. They can
remain in raw storage for later work.

AFLOW total energies stay in the raw table. The structure transform leaves its
energy fields empty so that shared MP correction code cannot use AFLOW energies
with guessed U values or pseudopotentials. Other source transforms are unchanged.
A future energy adapter needs actual source settings and a reviewed correction
policy.

## Tests

The new offline tests load exact production methods, replacing only dependency
imports and database, HTTP and process-pool boundaries. After correcting an
initial test-fixture setup error, four tests failed on the original behavior and
one passed. The first fixes made five pass. Astra then reproduced a worker-crash
case that the inherited pagination still ignored. Its new regression failed;
the parent-side pagination fix made all six pass on Python3.12. New-file lint
checks pass. The regular dependency-backed transform/fetch tests were updated too.

These checks do not replace a real PostgreSQL or multiprocessing test. The full
AFLOW suite still needs the approved dependency runtime; none was installed here.
No data was downloaded and no model was trained.
